# Ticket Booking System – Problem Statement

## Project Title
**Ticket Booking System**

## Problem Statement
The Ticket Booking System is a Python-based application designed to simplify the process of booking and managing tickets. The system allows users to check whether the tickets availability, select a ticket type, enter customer details, specify the number of tickets, and complete a booking.

The system automatically calculates the total no. of ticket cost and generates a unique booking ID for every  other successful booking tickets. Users can also view all bookings  tickets and cancel an existing their booking tickets. When a booking ticket is cancelled, the corresponding tickets are added back to the available ticket count.

## Objectives
- To provide a simple and user-friendly ticket booking system.
- To display available ticket types and their prices.
- To allow users to book one or more tickets.
- To automatically calculate the total booking amount.
- To generate a unique booking ID.
- To store customer and booking information during program execution.
- To allow users to view existing bookings.
- To provide a ticket cancellation facility.
- To update ticket availability after booking or cancellation.

## Scope
This project is based on ticket booking application developed for learning Python programming. It demonstrates concepts such as dictionaries, lists, functions, loops, conditional statements, exception handling, and user input.

The current version stores data in memory, so booking information is lost when the program is closed. It can be extended in the future with a database, graphical interface, authentication, online payment, and permanent data storage.

## Expected Outcome
The expected outcome is a functional Python application that enables users to view, book, manage, and cancel tickets through a simple menu-driven interface.
